# Maintainer notes

Not part of the published documentation. These are findings about the Reportnet 3
API itself — quirks, permission behaviour, and results from live testing — kept
because they were expensive to establish and are not written down anywhere else.

The user-facing documentation lives in `docs/` and is written for reporters.

| File | What it holds |
|---|---|
| `api-notes.md` | API behaviour that is not in the Swagger spec, or contradicts it |
| `live-tests-2003.md` | Measured results from live runs against dataflow 2003 |
| `live-tests-2003.json` | Raw data behind those measurements |
