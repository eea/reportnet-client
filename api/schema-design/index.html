    Schema design

    For custodians designing a dataflow. Needs a login token, not an API key: create the client with ReportnetClient.from_tokens(). See Designing schemas for a walk-through.

    designer = client.for_dataflow(11468).design(48097)
sites = designer.add_table("Sites", mandatory=True)

    TokenPair dataclass

    An access token and the refresh token that renews it.

    The refresh token rotates: every refresh returns a new one and the old one should be treated as spent. Persist the newest pair, never the first.

    TokenAuth

    Bases: Auth

    Send Authorization: Bearer <access token> and keep the token fresh.

    • Before a request, if the access token expires within 60 seconds (read from its JWT exp claim), it is refreshed first.
    • On a 401, or a gateway 500 that wraps one, it refreshes once and resends the request. Resending is safe: the server refused the request before acting on it.
    • The refresh token rotates; the newest pair is kept and passed to on_refresh so the caller can store it.
    • A lock stops two threads refreshing at the same time.

    Name Type Description Default
    access_token str

    The accessToken from the web app's login session.

    		 required
    refresh_token str

    The matching refreshToken.

    		 required
    base_url str

    API host that issues tokens.

    		 required

    Called with the new :class:TokenPair after each refresh.

    		 None
